# Contributions et vérification

Merci de conserver les sources réelles (notebooks Databricks exportés) distinctes des instructions et améliorations proposées.

Avant toute Pull Request :

1. Exécuter `python scripts/check_repo.py`.
2. Vérifier qu'aucune donnée d'identification personnelle, mot de passe ou clé API n'est ajoutée.
3. Ouvrir le PBIP avec Power BI Desktop, reconfigurer `DataRoot`, actualiser et vérifier les KPI.
4. Vérifier les modifications TMDL, les quatre pages et les relations du modèle.
5. Expliquer les impacts sur les chiffres de janvier 2024 et citer toute nouvelle source de données.

La licence MIT du code est distincte de la Licence Ouverte des données RTE / ODRE.
